# DevFlow Icons

71 open source icons for developer tools: version control, CI, servers, workflow
boards, tickets, status, and the app UI around them. One outline style drawn on
a 24px grid with a 2px stroke. Every icon inherits `currentColor`, so it takes
your text color with no extra styling.

## Usage

SVGs live in `icons/`, one file per icon. The set is also packaged as a single
IconifyJSON file, `devflow.json`, which is the format [Iconify](https://iconify.design)
and most icon frameworks consume.
